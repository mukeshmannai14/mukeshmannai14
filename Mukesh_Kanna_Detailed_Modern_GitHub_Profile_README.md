# 🚀 Featured Projects

## 🛒 01 — ShopHub | MERN E-Commerce Platform

> **A complete full-stack e-commerce application demonstrating authentication, product management, cart workflows, order processing and online payments.**

### 🎯 Project Objective

ShopHub was developed to simulate a real-world e-commerce platform where users can browse products, manage their shopping cart, complete checkout, make online payments and track their orders.

The project also includes administrative functionality for managing products and controlling order-related workflows.

### ✨ Key Features

- 🔐 User registration and login
- 🛡️ JWT-based authentication
- 👤 Protected user functionality
- 🛍️ Product listing and product management
- 🔎 Product browsing
- 🛒 Add/remove/update cart items
- ⚡ Redux Toolkit for centralized cart state
- 📦 Order creation and order history
- 💳 Razorpay payment integration
- 🔍 Payment verification workflow
- 👨‍💼 Admin authorization
- 🗄️ MongoDB database persistence
- 📱 Responsive frontend
- 🚀 Cloud deployment

### 🧠 Engineering Highlights

**Frontend Architecture**
- Built reusable React components
- Used Redux Toolkit to manage cart/application state
- Used Axios for API communication
- Implemented protected routes

**Backend Architecture**
- Created RESTful APIs with Express.js
- Designed MongoDB schemas using Mongoose
- Implemented authentication middleware
- Added authorization for admin functionality

**Payment Workflow**
1. User adds products to cart
2. Checkout calculates order information
3. Backend creates a Razorpay order
4. Razorpay handles payment
5. Payment response is verified
6. Order is stored in MongoDB

### 🛠️ Technology Stack

`React.js` `Redux Toolkit` `Node.js` `Express.js` `MongoDB` `Mongoose` `JWT` `Razorpay` `Axios` `Vercel` `Render`
